# SNAKE GAME

A simple Snake game built using Java Swing.

## Features

- Snake movement using arrow keys
- Apple/food generation
- Snake growth
- Score tracking
- Collision detection
- Game over screen
- Restart functionality

## Technologies

- Java
- Java Swing
- AWT

## How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run the `Main` class

## Controls

| Key | Action |
|-----|--------|
| ⬆️ | Move Up |
| ⬇️ | Move Down |
| ⬅️ | Move Left |
| ➡️ | Move Right |
